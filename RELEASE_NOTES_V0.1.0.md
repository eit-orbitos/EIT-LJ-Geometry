# v0.1.0 - Initial Reproducible Preprint Package

This release contains the first frozen research package for geometry-dependent equilibria in a generalized inverse-power model.

Highlights:
- analytic generalized equilibrium equation;
- radial geometry-factor model;
- simplex cancellation checks;
- regular polygon scan N=3..1000;
- five Platonic-solid calculations;
- controlled cube-to-cuboid deformation experiment;
- normalization-sensitivity robustness analysis;
- 5 regression tests;
- publication figures, manuscript, citation metadata, and independent-review prompts.

Scientific status:
- theoretical/computational;
- internally reproducible;
- not experimentally validated;
- heuristic interval [0.9,1.3] remains non-derived.
